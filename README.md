# codex-cli-themes

Codex CLI themes stored as single `.tmTheme` files under `themes/`.

## Themes

- [Code Dark](themes/codedark.tmTheme)
- [Coffee](themes/coffee.tmTheme)
- [Felipec](themes/felipec.tmTheme)
- [IR_Black](themes/ir-black.tmTheme)
- [Jellybeans](themes/jellybeans.tmTheme)
- [Tundra](themes/tundra.tmTheme)

## Qoder

Qoder CLI does not read `.tmTheme` files; its UI themes are JSON. Themes live under `qoder/themes/` and are activated via `ui.theme` in `.qoder/settings.json`:

- [Code Dark](qoder/themes/codedark.json)
